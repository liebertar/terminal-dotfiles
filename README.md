# terminal-dotfiles

Ghostty + tmux + zsh config for macOS.

## Quick Install

```bash
git clone https://github.com/liebertar/terminal-dotfiles.git
cd terminal-dotfiles
chmod +x install.sh && ./install.sh
```

## What's Included

- **Ghostty** — GitHub dark theme, JetBrains Mono, borderless window, blur
- **tmux** — Ctrl+A prefix, vim-style pane nav, git branch in status bar
- **zsh** — colored prompt with git branch, syntax highlighting, autosuggestions

## Fonts

Install before use:
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/)
- [D2Coding](https://github.com/naver/d2codingfont)
